# UniTrack | التدريب التعاوني في عسير

نموذج أولي لواجهة عربية تساعد الطلاب في منطقة عسير على استكشاف فرص التدريب التعاوني.

## وش تقدّم النسخة الحالية؟
- واجهة للطالب تعرض فرصًا تجريبية، مع إمكانية تصفيتها حسب التخصص والمدينة والمرحلة الدراسية.
- واجهة لجهة التدريب تعرض أمثلة على طلبات الطلاب وتتيح تجربة قبول الطلب أو رفضه.

## طريقة التجربة
نزّل ملف `index.html` وافتحه في المتصفح. تستخدم الواجهة بيانات تجريبية، ويمكن استكشافها دون تسجيل حساب.

## التقنيات المستخدمة
HTML وTailwind CSS وJavaScript.
